# 기물 선택 조작 — 2026-10-02

## 적용 흐름
- 기물 클릭: 좌측 초상/능력치/HP/SP/스킬 정보, 선택 기물 확대, 원래 시간 배속의 15%.
- 아군 기물 주변에 이동·공격·스킬 버튼 표시. 적은 정보만 표시.
- 이동/대상형 명령 선택: 전체 보드 시점으로 복귀하되 감속 유지. 목표 클릭으로 실행 요청.
- 자신/대상 없음 수동 스킬: 준비 완료 상태에서 버튼으로 바로 발동 요청.
- 명령 접수 성공, 우클릭/ESC, 좌측 닫기, 선택 기물 사망, 전투 종료 시 정보창·감속 해제. 원래 카메라와 시간 배속 복원.
- 선택 화면에서는 이동/공격 범위 표시를 기존 보드 강조 기능으로 제공한다. 실제 행동 해석은 기존 런타임을 재사용한다.
- 일반 선택 확대는 모든 기물에 적용한다. 별도의 스킬 연출 클로즈업은 기존 5성 제한 유지.

## 질문 목록 (현재 동작과 분리)
1. 선택 감속 15%가 적절한가? 현재 완전 정지는 하지 않는다.
2. 목표 클릭 즉시 명령을 접수하는 흐름을 유지할지, 스킬에만 추가 확인 단계를 둘지?
3. 적 기물도 정보 열람 시 같은 감속을 적용하는 편이 좋은가? 현재는 동일하게 적용한다.

초상은 기존 에셋을 사용하며, 없는 기물은 기물 문자로 표시한다. 전신 일러스트 제작은 별도 콘텐츠 작업이다.

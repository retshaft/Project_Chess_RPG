13개 모두 실제 평가 노멀 기준 UV 분할 누락 0건, 검사 허용오차 내 중첩 0건이다. 그러나 패킹 점유율은 19.18~66.30%이며, 엄격한 면적 기반 TD ±5%는 LowWall, Cylinder, Pillar, Platform 4개만 통과한다. **전체 완성 또는 베이크 준비 완료가 아니다.**

## 3. Specific Defect Breakdown

- **Cylinder**: 기존 옆면 32개 패널을 하나의 연결된 직사각형 띠로 복구. 캡 두 개는 본래 각각 단일 n-gon이다. 규정의 '원통 정확히 3개 아일랜드'를 유지하면서 '단일 폴리곤 아일랜드 0개'를 문자 그대로 만족시키는 것은 이 토폴로지에서 불가능하다. 두 캡은 구조적 예외로 기록하되 전체 SEC-03을 통과 처리하지 않는다. 점유율 46.23%이므로 독립 텍스처 대신 공용 아틀라스 대상으로 분류한다.
- **BigGear / Crank**: 각각 점유율 19.18% / 24.31%. 일부 띠를 직선화했어도 전체 둘레의 연속 띠 구조가 완성된 것은 아니다. 단일 면 패치가 각각 128개 / 194개 남는다. 이런 상태로 2K 텍스처 세트를 각각 배정하면 공간 낭비가 크다.
- **LowWall**: 하드 경계로 둘러싸인 단일 면 패치가 308개 남는다. TD 통과만으로 제작 적합하다고 볼 수 없다. 벽·기둥의 평판, 베벨, 부품 끝단을 실제 구조별로 구분해 후속 수정해야 한다.
- **FortressPillar**: TD 약 26.40~54.60 px/m, 평균 약 34.04 px/m. 넓은 편차가 남으므로 정규화 완료 아님.
- **Crank**: TD 약 2.54~4.98 px/m, 평균 약 3.65 px/m. 사용 크기와 해상도 적합성을 먼저 검토해야 한다.
- **Stairs / NarrowConnecter / Path**: 일부 비직사각형·곡면 패치의 면적 편차가 남는다. 스케일만 다시 맞추면 아일랜드 내부 왜곡이 사라지는 것은 아니다.

아일랜드/패치 개수는 `rebuild_topology_report.json`의 기하 패치 통계다. 모든 기하 패치 개수가 최종 UV 연결 성분 개수와 동일하다고 단정하지 않는다.

## 4. Actionable Correction Workflow

1. **부품별 형상 구분:** BigGear/Crank의 전후면, 치형 외곽, 내경, 베벨을 별도 선택 집합으로 지정한다. 자동 각도 분할만으로 전체 둘레를 만들지 않는다.
2. **셰이딩과 연결 띠 조율:** 하드 노멀을 유지해야 하는 치형 모서리를 넘는 단일 띠는 SEC-02와 충돌한다. 필요한 베벨/전이 토폴로지를 설계하고 셰이딩을 확인한 뒤, 부드러운 연결 구간만 묶는다. 하드 에지를 무조건 소프트 처리해 검사 수치를 맞추지 않는다.
3. **평판과 캡 구분:** 벽의 연속 평면은 이어 붙이고, 단독 부품의 끝면·원통 캡은 구조적 예외 목록으로 기록한다. 단일 면 결함을 숨기기 위해 임의로 면 분할하지 않는다.
4. **변폭 띠 보정:** 전이부는 필요한 최소 릴리스 컷을 추가한다. 쿼드 순서를 정리한 뒤 실제 길이 비율로 Follow Active Quads/직선화를 적용하고 삼각형 TD 편차를 다시 측정한다.
5. **반복 부품 스태킹:** 동일 크기·형상·재질·베이크 조건의 반복 장식을 식별한다. 런타임 UV와 베이크 UV를 분리하고, 베이크 제외 복제면만 U+1로 이동한다. 비대칭 AO가 필요한 부품은 공유하지 않는다.
6. **공용 아틀라스:** 실제 Unity 사용 크기를 기준으로 공통 TD를 정하고 저복잡도 부품을 공용 시트에 패킹한다. 같은 TD와 필요한 여백을 유지한 상태에서 70% 이상을 검사한다. 단순 점유율 충족을 위한 임의 확대 금지.
7. **최종 검증:** 삼각분할·노멀·UV를 고정한 저폴리 출력에서 Normal/AO 베이크, 체크 패턴, 옆광선 회전, 밉맵 거리 확인을 수행한다. 이후 Unity에서 같은 탄젠트 기준으로 확인한다.

# 얕게 침수된 기계 유적지 — 바닥과 식생 준비

위치: `Assets/Environment/MechanicalRuins/`

| 파일 | 용도 |
|---|---|
| Materials/MechanicalFloor.mat | 회색 콘크리트 + 산화된 기계 금속판 바닥. 기존 바닥 Renderer에 드래그 |
| Prefabs/MechanicalFloor.prefab | 4×4m 바닥 표면 샘플. 충돌체 없음 |
| Prefabs/MossPatch.prefab | 1.5m 이끼 패치. 바닥 표면보다 1~2cm 높게 배치 |
| Prefabs/GrassCluster.prefab | 3개의 양면 카드를 교차한 풀 묶음. 바닥을 기준으로 배치하고 회전/크기 조정 |
| Textures/*.png | 세 에셋의 원본 색상 이미지. 이끼/풀은 실제 알파 포함 |

물 위치, BattleScene 및 기존 바닥 머티리얼은 수정하지 않았다. 풀과 이끼에는 충돌체와 실행 스크립트가 없다.

## 사용

1. Project에서 위 폴더의 Materials 또는 Prefabs를 찾는다.
2. 바닥 머티리얼은 선택한 바닥에 적용하거나 MechanicalFloor 프리팹을 배치한다. 기본 이미지 한 장을 4m 모듈로 사용한다. 넓은 면에서 반복 경계는 실제 배치 시 확인한다.
3. MossPatch를 틈새·가장자리에 얹고 크기와 Y 회전을 바꿔 반복감을 줄인다. 이끼는 **평면 메시 데칼**이며 굴곡에 자동으로 투영되는 Decal Projector가 아니다. 경사진 바닥에서는 해당 면에 맞춰 회전한다.
4. GrassCluster를 갈라진 틈이나 모서리에 배치한다. 정적인 카드 식생이며 바람 애니메이션은 포함하지 않는다.

색상 텍스처 기반의 준비 에셋이다. 독립적인 노멀·높이·금속 마스크를 갖춘 완전한 PBR 세트는 아니다. 바닥은 중성 반사값, 식생은 낮은 광택으로 설정했다. 풀/이끼는 URP Lit 양면 Alpha Clip 0.5, 깊이 쓰기와 밉맵 알파 커버리지 보존을 사용한다. 물의 불투명 장면 복사에 포함될 수 있는 컷아웃 방식이다. 가장자리의 알파 1~2/255 색 흔적은 잘라내기 대상이다.

## 검증 및 제한

- 생성 이미지의 외형을 확인하고 풀의 투명 배경을 재생성했다. 이미지 크기는 도구 실제 출력 1254×1254이며 임포트에서 비정규 해상도를 강제 확대하지 않는다.
- 원본 PNG 알파, 머티리얼/텍스처 GUID 연결 및 프리팹 내부 참조를 파일 수준에서 확인했다. 식생 두 이미지의 모서리 알파는 0이다.
- 다른 작업의 Unity 실행권이 유지 중이어서 에디터를 조작하거나 씬에 배치하지 않았다. Unity 임포트 및 실제 렌더 검증은 대기 상태다. 에셋 준비 작업이라 전투 테스트와 Play Mode는 실행하지 않았다.

## 생성 기록

OpenAI 기본 내장 image_gen 도구로 생성했다. 생성 프롬프트는 아래 별도 파일에 기록한다. 원본의 실제 알파를 보존해 프로젝트로 복사했다.

## 1. 3성 캐릭터 설계 밸런스 기준선 (Design Guidelines)

1. **5성과의 차별화:**
   - 5성 에이스(엘레나, 키아라, 베스타)가 극단적인 특수 기믹(근접 사각지대 저격 +30% 증폭, 2연타 출혈 방무, 대장갑 40% 트루뎀)과 전용 컷인 궁극기를 보유한다면,
   - **3성 캐릭터는 직관적이고 안정적인 성능**을 제공하여 덱의 기본 뼈대(전선 형성, 지속 힐링, 정석 넉백, 자원 펌핑)를 담당합니다.
2. **스탯 기준선 (Lv 1 기준):**
   - 5성 대비 약 **70~75%의 기초 스탯**을 배정합니다.
3. **스킬 구조의 단순성:**
   - [패시브 1종] + [단일 액티브 1종] (SP 요구량 35~60의 빠른 회전율)

## 3. 기물별 상세 캐릭터 스펙 시트

### 3.1. 폰 (Pawn | Light | 8 AP | 배치 코스트 1)

#### ① 레오 (Leo) — 전선의 눈 (척후대 / Vanguard)
- **비주얼:** 경량 전술 조끼, 카고 팬츠, 통신 헤드셋과 경량 단검
- **기본 스탯 (Lv 1):** HP 320 / DEF 10 / RES 5% / ATK 55 / 선딜 2.5초 / 이속 0.8u/s
- **전술 기믹:** 전선 시야 확보 및 실시간 AP 자원 펌핑 요원
- **스킬셋:**
  - **[패시브] 전술 통신 (Tactical Link):** 필드에 생존해 있는 동안 초당 **+0.8 AP**를 지속 생산합니다.
  - **[액티브] 선봉 기동 (Vanguard Sprint):** (SP 40, 자동 회복) 즉시 다음 1회 이동에 소모되는 AP가 0이 되며, 이동 후 5초간 방어력이 +15 증가합니다.
- **프로모션:** 적진 8열 도달 시 표준 룩(포트리스)으로 승급.

#### ② 바론 (Baron) — 강철의 방패 (방어대 / Defender)
- **비주얼:** 풀페이스 진압 헬멧, 전면을 덮는 대형 복합소재 진압 방패
- **기본 스탯 (Lv 1):** HP 420 / DEF 28 / RES 10% / ATK 40 / 선딜 2.5초 / 이속 0.8u/s
- **전술 기믹:** 고방어력 고기방패, 폰 단계의 든든한 방어선 형성
- **스킬셋:**
  - **[패시브] 전열 고정 (Hold the Line):** 기본 공격 시 AP를 소모하지 않습니다(0 AP). 인접한 적이 이동하려 할 때 요구 AP를 +4 증가시킵니다.
  - **[액티브] 방패 참호 (Shield Trench):** (SP 45, 피격 회복) 8초간 자신에게 3칸 이내 적의 어그로를 끄는 [도발]을 부여하고 받는 모든 물리 피해를 30% 감쇄합니다.
- **프로모션:** 적진 8열 도달 시 표준 룩(포트리스)으로 승급.

#### ③ 클로에 (Chloe) — 번갯불 칼날 (돌격대 / Charger)
- **비주얼:** 가벼운 라이더 자켓, 부스터 장착 앵클부츠, 트윈 숏소드
- **기본 스탯 (Lv 1):** HP 280 / DEF 8 / RES 5% / ATK 75 / 선딜 2.0초 / 이속 1.1u/s
- **전술 기믹:** 빠른 킬 캐치 및 AP 환불을 통한 템포 스노우볼
- **스킬셋:**
  - **[패시브] 틈새 공략 (Opportunity Strike):** 기본 공격에 소모되는 AP가 0입니다. 자신의 공격으로 적 기물을 처치할 때마다 **15 AP를 즉시 환불**받습니다.
  - **[액티브] 돌파 찌르기 (Breach Thrust):** (SP 35, 공격 회복) 전방 1칸의 적에게 공격력 190%의 물리 피해를 입히고 대상을 [비틀거림] 상태로 만듭니다.
- **프로모션:** 적진 8열 도달 시 돌격기사(나이트)로 승급.

#### ④ 로빈 (Robin) — 숲의 감시자 (사수 / Marksman)
- **비주얼:** 카모플라주 판초 후드, 소형 컴파운드 크로스보우
- **기본 스탯 (Lv 1):** HP 260 / DEF 5 / RES 5% / ATK 68 / 선딜 2.0초 / 이속 0.8u/s
- **전술 기믹:** 폰 진형의 후방 화력 지원, 유연한 타격 각도
- **스킬셋:**
  - **[패시브] 곡사 조준 (Curved Aim):** 전방 대각선 1칸뿐만 아니라 전방 ㄱ자 모양(나이트의 타격점 2칸)까지 원거리 타격할 수 있습니다.
  - **[액티브] 다리 묶기 볼트 (Pinning Bolt):** (SP 50, 자동 회복) 사거리 내 적에게 공격력 180%의 물리 피해를 가하고 3초간 대상의 이동 속도를 35% 저하시킵니다.
- **프로모션:** 적진 8열 도달 시 표준 비숍(대주교)으로 승급.

### 3.2. 나이트 (Knight | Middle | 24 AP | 배치 코스트 3)

#### ⑤ 카일 (Kyle) — 창공의 돌격병 (돌격기사 / AssaultKnight)
- **비주얼:** 네오-중세 기사 흉갑, 기병 랜스와 원형 버클러
- **기본 스탯 (Lv 1):** HP 540 / DEF 24 / RES 5% / ATK 125 / 선딜 0.8초 / 이속 2.5u/s (SpeedLevel 5)
- **전술 기믹:** 장애물을 무시하고 뛰어넘는 가장 스탠다드한 단일 물리 딜러
- **스킬셋:**
  - **[패시브] 기동 가속 (Momentum Leap):** L자 점프 이동 직후 가하는 첫 번째 기본 공격의 공격력이 **+30% 증가**합니다.
  - **[액티브] 랜스 임팩트 (Lance Impact):** (SP 50, 자동 회복) 적에게 공격력 220%의 강력한 일격을 가하며 대상 기물을 1칸 뒤로 밀쳐냅니다(Knockback Force 1).

#### ⑥ 롤랑 (Roland) — 충성의 서약 (근위기사 / GuardKnight)
- **비주얼:** 묵직한 백은색 플레이트 아머, 기사단 장검과 타워 쉴드
- **기본 스탯 (Lv 1):** HP 620 / DEF 35 / RES 10% / ATK 105 / 선딜 1.1초 / 이속 2.0u/s (SpeedLevel 4)
- **전술 기믹:** 핵심 아군(킹/원거리) 보호 및 진입 차단형 서브 탱커
- **스킬셋:**
  - **[패시브] 수호 오라 (Guard Aura):** 자신 주변 1칸 이내에 위치한 모든 아군 기물의 물리 방어력을 **+20** 증가시킵니다.
  - **[액티브] 방패 강타 (Shield Bash):** (SP 45, 자동 회복) L자 범위의 적 1명에게 도약 착지하여 공격력 150% 물리 피해를 주고 **1.5초간 기절(Stun)**시킵니다.

#### ⑦ 루카스 (Lucas) — 단죄의 망치 (성기사 / Paladin)
- **비주얼:** 황금빛 상감 로브를 두른 은빛 갑옷, 양손 홀리 메이스
- **기본 스탯 (Lv 1):** HP 520 / DEF 22 / RES 20% / ATK 115 / 선딜 1.1초 / 이속 2.0u/s (SpeedLevel 4)
- **전술 기믹:** 물리 방어력이 극도로 높은 적 '룩'을 카운터치는 마법 나이트
- **스킬셋:**
  - **[패시브] 신성 인챈트 (Holy Smite):** 기본 공격이 물리 피해 대신 **100% 마법 피해**로 전환됩니다. (상대 물리 방어력을 무시하고 마법 저항력으로 연산)
  - **[액티브] 심판의 빛 (Judgement Radiance):** (SP 55, 자동 회복) 대상 적에게 공격력 180%의 마법 피해를 가하고 6초간 대상의 마법 저항력을 20% 깎아내립니다.

### 3.3. 비숍 (Bishop | Middle | 24 AP | 배치 코스트 3)

#### ⑧ 셀레나 (Selena) — 별빛의 서곡 (대주교 / Archbishop)
- **비주얼:** 우아한 군청색 마법사 로브, 부유하는 에테르 오브
- **기본 스탯 (Lv 1):** HP 400 / DEF 12 / RES 15% / ATK 165 / 선딜 1.5초 / 이속 1.5u/s (SpeedLevel 3)
- **전술 기믹:** 대각선 사거리의 정석적인 마법 누커
- **스킬셋:**
  - **[패시브] 원격 공명 (Distant Resonance):** 대각선 2칸 이상 떨어진 대상 타격 시 마법 피해량이 **+15% 증가**합니다.
  - **[액티브] 에테르 버스트 (Aether Burst):** (SP 50, 자동 회복) 대각선 사거리 내 적 1명에게 공격력의 **260%에 달하는 고농축 마법 폭발**을 작렬합니다.

#### ⑨ 노아 (Noah) — 생명의 촛불 (사제 / Priest)
- **비주얼:** 에메랄드빛 테두리의 온화한 사제복, 고풍스러운 회복 랜턴
- **기본 스탯 (Lv 1):** HP 420 / DEF 10 / RES 20% / ATK 110 / 선딜 1.5초 / 이속 1.5u/s (SpeedLevel 3)
- **전술 기믹:** 덱의 유지력을 책임지는 표준 메인 힐러
- **스킬셋:**
  - **[패시브] 자애로운 인도 (Compassion):** 일반 공격 시 적을 공격하지 않고, 사거리 내에서 **현재 HP 비율이 가장 낮은 아군을 공격력의 70%만큼 즉시 치유**합니다.
  - **[액티브] 축복의 기도 (Prayer of Grace):** (SP 40, 자동 회복) 지정 아군 1명의 체력을 공격력의 220%만큼 대량 회복시키고, 대상에게 걸린 모든 해로운 상태이상을 정화합니다.

#### ⑩ 에녹 (Enoch) — 정화의 불꽃 (이단심문관 / Inquisitor)
- **비주얼:** 검은 트렌치코트, 챙 넓은 모자, 화염 방사 랜턴과 성유 병
- **기본 스탯 (Lv 1):** HP 430 / DEF 15 / RES 15% / ATK 140 / 선딜 1.5초 / 이속 1.5u/s (SpeedLevel 3)
- **전술 기믹:** 밀집된 적 보병대(폰 라인)를 소탕하는 십자 광역 마법사
- **스킬셋:**
  - **[패시브] 확산 화염 (Spreading Flame):** 기본 공격 적중 시, 대상 타일 및 인접한 상하좌우 십자(+) 1칸 타일에 공격력 40%의 스플래시 마법 피해를 입힙니다.
  - **[액티브] 인퀴지션 크로스 (Inquisition Cross):** (SP 60, 자동 회복) 지정 타겟을 중심으로 거대한 십자 화염을 일으켜 5칸 타일의 모든 적에게 공격력 170% 마법 피해를 입히고 5초간 [화상]을 부여합니다.

### 3.4. 룩 (Rook | Heavy | 36 AP | 배치 코스트 4)

#### ⑪ 브록 (Brock) — 무너지지 않는 성벽 (포트리스 / Fortress)
- **비주얼:** 육중한 중장갑 강화 외골격, 전면 직사각형 타워 실드
- **기본 스탯 (Lv 1):** HP 880 / DEF 50 / RES 10% / ATK 135 / 선딜 2.0초 / 이속 1.1u/s (SpeedLevel 2)
- **전술 기믹:** 압도적인 물리 방어력과 전선 밀어내기(넉백) 메인 탱커
- **스킬셋:**
  - **[패시브] 중장갑 보강 (Reinforced Plating):** 체급 3 (Heavy, Weight 3). 받는 물리 피해를 계산할 때 최종 데미지에서 **-8 추가 감산**을 적용합니다.
  - **[액티브] 실드 스매시 (Shield Smash):** (SP 50, 피격/자동 회복) 전방 직선 1칸의 적에게 공격력 160% 물리 피해를 가하고 **2칸 뒤로 밀쳐냅니다 (Force 2)**. (벽이나 기물에 충돌 시 Splat MaxHP 10% 고정 피해 유도)

#### ⑫ 이그니스 (Ignis) — 고대의 보루 (마탑 / MagicTower)
- **비주얼:** 청빛 룬 문양이 빛나는 비전 석조 골렘 흉갑, 포구형 건틀릿
- **기본 스탯 (Lv 1):** HP 820 / DEF 30 / RES 40% (0.40) / ATK 145 / 선딜 2.0초 / 이속 1.1u/s (SpeedLevel 2)
- **전술 기믹:** 적 비숍/마법 공격을 받아내는 마법 저항 탱커 및 대(對)룩 마법 포격수
- **스킬셋:**
  - **[패시브] 룬 프로텍션 (Runic Warding):** 마법 저항력이 기본 **40%**로 매우 높으며, 기본 공격이 **마법 피해**로 적용되어 상대 룩을 효과적으로 타격합니다.
  - **[액티브] 마력 역류파 (Mana Disruptor):** (SP 55, 자동 회복) 전방 직선 상의 적 1명에게 공격력 190%의 마법 피해를 입히고 **2.5초간 [침묵(Silence)]** 상태로 만들어 스킬 시전을 차단합니다.

#### ⑬ 테레사 (Teresa) — 수호의 날개 (수호자 / Guardian)

## 4. 덱 빌딩 시너지 추천 가이드

1. **[정석 밸런스 덱 (안정형)]**
   - 구성: **레오 (척후대)** + **바론 (방어대)** + **카일 (돌격기사)** + **노아 (사제)** + **브록 (포트리스)**
   - 운용: 바론과 브록이 전선을 형성하고, 레오가 초당 +0.8 AP를 공급하며, 노아가 힐을 전담하는 사이 카일이 적 취약점을 L자로 찔러 암살합니다.
2. **[마법 관통 카운터 덱 (대 룩 전용)]**
   - 구성: **로빈 (사수)** + **루카스 (성기사)** + **셀레나 (대주교)** + **이그니스 (마탑)**
   - 운용: 적이 물리 방어력이 높은 룩/방어대 위주일 때, 루카스와 셀레나, 이그니스의 마법 피해로 물리 방어선을 완전히 무력화합니다.
3. **[스노우볼 템포 덱 (속도전)]**
   - 구성: **클로에 (돌격대)** + **레오 (척후대)** + **카일 (돌격기사)** + **에녹 (이단심문관)**
   - 운용: 에녹의 십자 광역기로 적들의 체력을 깎고, 클로에가 막타를 쳐 15 AP를 연속 환불받으며 전장을 빠르게 밀어붙입니다.

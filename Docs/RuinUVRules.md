# 유적 모듈 UV 검증 계약

2026-09-13 사용자 제공 8대 규칙을 기준으로 한다. 작업본은 ArtSource/MechanicalRuins/Ruin_UV_verified.blend이며 파일 이름은 통과 보증이 아니다. 실제 판정은 검사 결과를 따른다.

## 검사 조건

- 모듈당 독립된 2048×2048 베이크 텍스처, 활성 렌더 UV는 BakeUV.
- 타일은 1001 (0~1). 외곽 목표 여백 24.576px, 아일랜드 간 최소 8px, 권장 16px.
- 밀도는 표면 삼각형의 실제 3D 면적과 UV 면적으로 계산한다. 현재 실제 크기를 기준으로 px/m을 기록한다. 에셋 내 균일성 허용 편차는 ±5%로 검사하되, 프로젝트 공통 절대 TD 값은 확정되지 않았으므로 별도 지정이 필요하다.
- 00: 활성 베이크 UV의 전 좌표와 캔버스 여백 검사.
- 01: 명시된 샤프 에지 및 면 노멀 불연속 경계의 양 끝 UV 좌표를 비교한다. 모디파이어 평가 후의 최종 노멀 경계는 별도 검증 전까지 완전 통과로 간주하지 않는다.
- 02: 인접 면 법선의 각도가 60도 이상인 경계를 분리한다.
- 03: 축 정렬 패킹 실행만으로 스트립 직선화를 통과시킬 수 없다. 원통·베벨 스트립의 내부 행/열 직선성은 별도 검사한다.
- 04: 평균 밀도 정규화 이후에도 개별 삼각형의 변형을 검사한다. 통합 크기가 미정인 거대 모듈에 임의의 공통 수치를 강요하지 않는다.
- 05: UV 삼각형의 합집합으로 얻은 아일랜드 사이 실제 거리를 측정한다. 내부 오버랩이 있는 아일랜드는 여백 수치만으로 안전하다고 판정하지 않는다.
- 06: 이번 작업은 미러 공유를 사용하지 않고 고유 UV를 목표로 한다. 오프셋은 베이크에서 제외한 복제면에 한해서만 규칙 00의 예외다. 삼각형 교차 면적을 검사해 의도하지 않은 중첩을 찾는다.
- 07: 최종 카메라와 결합부가 정해지지 않은 모듈의 모든 심이 숨겨졌다고 단정하지 않는다. 하드 에지 분할 때문에 필요한 노출 심은 베이크·최종 셰이딩으로 확인해야 한다.

## 작업 범위

새 Blender 작업본과 비교 씬에서 생성된 덩굴·잎·줄기를 제거했다. 이전 작업본은 백업으로 남긴다. 재질 원본은 첨부 이미지에 맞춰 밝은 바위와 밝은 도장이 벗겨진 녹슨 금속으로 변경했다. 베이크 완료 맵이 아니라 수정 가능한 Blender 재질 소스다.

검사 실패 항목이 남은 상태에서 베이크 성공이나 AAA 제작 완료라고 보고하지 않는다. 이번 UV 작업본을 Unity 프리팹에 자동 덮어쓰지 않는다. 이전 Unity ReferenceVariant 프리팹은 이전 출력물이며, 새 작업본으로 교체되기 전에는 사용하지 않는다.

## 현재 검사 결과 — 전체 판정 Fail (보완 필요)

13개 모듈의 활성 BakeUV를 검사했다. 아래 Fail에는 결함뿐 아니라 완료를 입증하지 못한 항목도 포함된다.

| 규칙 | 판정 | 근거 또는 남은 작업 |
|---|---|---|
| 00 타일 내부 | Pass | 전 모듈 0~1 내부, 외곽 여백 약 24.576px |
| 01 하드 에지 분할 | Pass | 원본 및 모디파이어 평가 후 실제 코너 노멀 경계에서 UV 분할 누락 0 |
| 02 급경사 분할 | Pass | 60도 이상 경계의 UV 분할 누락 0 |
| 03 스트립 직선화 | Fail | 축 정렬 패킹은 수행했으나 곡선 스트립이 남아 있고 전체 직선화 검증 미완료 |
| 04 텍셀 밀도 | Fail | 에셋 내부 편차 ±5%는 13/13 통과. 모듈 간 공통 절대 TD와 실제 사용 크기 미확정 |
| 05 패딩 | Pass | 2K에서 아일랜드 최소 간격 16.119px, 외곽 약 24.576px |
| 06 오버랩 | Pass | 고유 UV 사용. 교차 면적 0.01 제곱픽셀 초과인 삼각형 중첩 0건 |
| 07 심 은닉 | Fail | 최종 카메라 기준 노출 심 검토 및 실제 베이크 후 반사광 경계 확인 미완료 |

UV 면적 점유율은 약 13.5~65.2%로, 특히 기어의 효율이 낮다. 작은 하드 서페이스 조각과 링 내부 빈 공간을 포함하므로 추가 패킹 및 직선화가 필요하다. 전체 밀도 기준이 정해지기 전 모듈당 2K 구성을 최종 출시 규격으로 확정하지 않는다.

BigGearBroken의 비평면 면 99개와 SmallPillar의 비평면 면 40개를 작업본에서 삼각분할하여 전개 후 면적 왜곡을 보정했다. 원본 및 이전 작업본은 보존했다. 노멀/AO 베이크, Unity 재출력과 인게임 확인은 이번 검사에 포함되지 않았다. 게임 코드 변경이 없어 컴파일 및 Play Mode 테스트는 실행하지 않았다.

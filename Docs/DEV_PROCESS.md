# Checkmate RPG — 개발 프로세스 가이드 (DEV_PROCESS)

> 기준일: 2026-09-08
> Codex 메인 개발자와 ZCode(GLM-5.3-Flash), Antigravity(Gemini)의 협업 기준이다.
> 작업 우선순위의 단일 기준은 [MILESTONES.md](MILESTONES.md)이다.
> 병렬 작업의 배정·소유권·인계·통합은 [Parallel/WORKFLOW.md](Parallel/WORKFLOW.md)를 따른다. 공통 원칙은 루트 AGENTS.md를 따른다.

---

## 1. 역할 분담

| 역할 | 담당 | 내용 |
|---|---|---|
| **개발 총괄** | Codex | 설계, 작업 분할, 파일 소유권, 코드 리뷰, 통합 및 최종 검증 |
| **병렬 구현** | ZCode / GLM-5.3-Flash, Antigravity / Gemini | 각자의 워크트리에서 배정 범위 구현·테스트·인계 |
| **실행 검증** | Codex 중심, 필요시 서브 AI 또는 사용자 | 공용 Unity 실행권을 확보하고 대상 프로젝트에서 컴파일·테스트·Play Mode 확인 |
| **기획 확정** | 사용자 | 수치·룰의 최종 결정 (AI는 기획서 근거가 없는 수치를 상수로 제안하고 표시) |

AI도 연결된 도구로 Play Mode 검증을 수행한다. 실행할 수 없는 항목만 사용자에게 최소 확인 절차를 안내한다. 검증 후 반드시 Play Mode를 종료한다.

## 2. 작업 사이클

```
① 작업 배정          → 메인이 우선순위·기준 커밋·허용 파일·완료 조건을 확정
② 병렬 구현          → 서브 AI가 독립 워크트리에서 구현·테스트·인계 커밋
③ 리뷰 및 순차 통합   → 메인이 diff와 근거 확인 후 통합 브랜치에 반영
④ 통합 검증          → 컴파일·기존 테스트·필요한 Play Mode 확인, 실패 시 수정
⑤ 문서 동기화        → 메인이 실제 검증 결과로 보드·마일스톤 갱신
```

**원칙**
- 이전 항목의 검증이 끝나지 않으면 다음 우선순위 기능을 추가하지 않는다. (MILESTONES 원칙 1·2 준수)
- 씬 구조 변경은 가능한 한 에디터 툴(`OutgameSceneBuilder` 등)로 수행하고, 수동 편집은 커밋 전에 Play Mode로 확인한다.
- 검증 결과와 문서가 다르면 문서를 고치지 말고 실제 동작을 먼저 확인한다.

## 3. 커밋 컨벤션

- 형식: `feat|fix|docs|refactor: 요약` (요약은 한국어 가능)
- 예시: `fix: 중복 지형 프로세서 제거로 Sanctuary/Spikes 이중 적용 해소`
- 백업 목적의 대량 커밋은 지양하고, 기능 단위로 커밋한다. 인계용 커밋은 미검증·실패 여부를 명시할 수 있지만 최종 완료나 main 반영의 근거로 삼지 않는다.

## 4. M1 세로 슬라이스 검증 체크리스트 (사용자 실행용)

> 소요 약 15분. 2026-09-07 기준, 빌드 설정이 루트 `Assets/Scenes/OutgameScene.unity`로 고정된 이후 버전.

| # | 절차 | 기대 결과 |
|---|---|---|
| 1 | Unity 6000.3.10f1로 프로젝트 오픈 | 콘솔에 컴파일 에러/경고 0 |
| 2 | `Assets/Scenes/OutgameScene.unity` 열고 Play | 타이틀/메인 로비 표시, 예외 없음 |
| 3 | 로비 → 작전 출격(스테이지 선택) → 덱 편성 → 출격 | `BattleScene`으로 전환, 유닛 스폰 + 그리드 등록 |
| 4 | 유닛 선택 → 이동 | 이동 가능 타일 오버레이 표시, AP 예측/소모 반영 |
| 5 | 유닛 선택 → 공격 → 스킬 | 사거리 판정, 피해 플로팅 텍스트, SP 충전 |
| 6 | AP를 소진한 뒤 이동/공격 시도 | 행동이 예측 가능하게 거부되고 피드백 표시 |
| 7 | 킹 사망 유도 | 결과 UI 표시, 재시작 동작 |
| 8 | 패배/승리 후 아웃게임 복귀 | **루트 OutgameScene(프리미엄 허브)으로 복귀** — 구버전 씬으로 돌아가면 즉시 보고 |
| 9 | 전 과정 콘솔 확인 | 치명 오류/예외 0 |

## 5. 버그 제보 템플릿

```
[재현 절차] 1. ... 2. ... 3. ...
[기대 동작] ...
[실제 동작] ...
[콘솔 로그] 에러 전문 (스택 트레이스 포함, 복사 붙여넣기)
[환경] 씬 이름, 실행 경로(아웃게임 진입 여부), 빌드/에디터 여부
```

콘솔 창 우클릭 → `Edit → Copy`로 스택 전체를 복사해 전달하면 원인 분석이 가장 빠르다.

## 6. 협업 파일 경계

| 파일 | 편집 주체 | 비고 |
|---|---|---|
| `Assets/Scripts/**` | 작업서에 지정한 AI | 같은 파일의 동시 편집 금지, 사용자 기존 변경 보존 |
| `Docs/MILESTONES.md`, `Docs/Parallel/BOARD.md` | Codex | 검증 결과와 배정 상태를 확인한 뒤 갱신 |
| `ProjectSettings/EditorBuildSettings.asset` | 필요할 때만 메인이 배정 | 씬 순서 변경이 요구되는 작업에 한정 |
| 씬(.unity)·프리팹 | 필요할 때만 한 AI에게 배정 | 기존 에디터 도구 우선, 변경 후 Play Mode 검증 |

# 물살 제어 — ShallowWaterMotion

BattleScene의 `Battle Shallow Water`에 `ShallowWaterMotion`을 적용했다.
스크립트: `Assets/Scripts/Water/ShallowWaterMotion.cs`.

## 조절
- Motion Speed: 전체 흐름 속도. 기본 0.75.
- Current Variation: 흐름 세기·횡방향 변화. 기본 0.18, 범위 0~0.35.
- Current Period: 흐름이 서서히 바뀌는 기준 주기. 기본 32초(레이어별 서로 다른 배수).
- Swell Variation: 큰 물결의 높이 변화. 기본 0.08. 기존 최대 진폭을 넘기지 않는다.
- Preview In Editor: 에디터 렌더 시에도 흐름 진행. 꺼도 Play에서는 작동한다.

네 파도의 파장별 전파 속도는 기존 분산 관계를 유지하며 각기 다른 완만한 변조를 준다. 세 잔물결 레이어에는 연속적인 전진 흐름과 느린 횡방향 흐름을 합친다. 시간에 변하는 속도를 절대 시간에 곱하지 않고 적분한 변위를 사용해 위상 점프를 방지한다. 전체 속도 변경도 누적 모션 시간에 반영한다. 장시간 실행 시 UV/위상을 감싸 정밀도 손실을 줄인다.

렌더 이벤트에서 갱신하며 Update 폴링과 반복 경로의 새 배열/재질 생성은 없다. 같은 게임 시간에 여러 카메라가 렌더해도 중복 진행하지 않는다. 스케일된 게임 시간 사용으로 일시정지/timeScale=0을 따른다. 반사 카메라에서는 재갱신하지 않는다.

Renderer MaterialPropertyBlock으로 이 물 오브젝트의 모션 입력만 바꾼다. 반사 컴포넌트의 입력을 읽고 유지하며 공유 머티리얼의 물색/투명도/반사 값은 수정하지 않는다. 컴포넌트를 끄면 기존 셰이더 움직임으로 돌아간다. 전환 시 위상 맞춤 크로스페이드는 없으므로 실행 중 껐다 켤 때 패턴 위치는 달라질 수 있다.

실제 유체 충돌/장애물 회피 시뮬레이션이나 캐릭터 물보라는 아니다. 배경 수면의 파도/흐름 표현 제어이며 포말·카우스틱의 기존 애니메이션 경로는 유지한다.

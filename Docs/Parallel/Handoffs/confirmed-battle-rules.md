## 변경
- 고정 편성 상한 20. 기준 편성은 킹(현재 3)+Q5+R4+B3+N3+폰 2명으로 20이다. 기물 기본 비용 P1/N3/B3/R4/Q5, 킹은 기존 슈트 데이터 값. 특수 예외 플래그로 명시적 덮어쓰기. 덱 이동 시 중복 비용 방지. 기존 저장 초과 덱은 보존하고 출격 전에 조정 안내.
- 킹 e1 자동 배치 및 카드 제외. 수동 배치 대원만 배치 단계 우클릭 철회/카드 복원. 미배치 대원 허용, 시작 시 앞줄 징집병 필수 충원.
- AbilityDefinition의 Manual/Automatic 구분. 기존 모든 스킬은 기본 Manual. 선택한 실제 스킬을 기존 행동 예약/해석/변경 기록 경로로 발동한다. 효과 목록이 비어 있으면 SP를 소모하지 않고 거절한다.
- 정식 생성 유닛에 SPComponent 연결. 전투 중 SP의 주인은 ActionRuntimeController이며 표시 컴포넌트의 프레임별 충전과 기존 Subclass의 완충 즉시 발동 경로를 중단했다.
- 선택 스킬의 SP 상한/초기치/회복 방식을 사용한다. 완충을 유지하며 성공적인 해석 시 SP를 소비한다. 자동 초당 1, 공격·피격 1(기존 SPComponent 기준). 기본 공격이 AbilityDefinition 경로인 경우도 공격 회복 처리.
- 자동 스킬은 현재 전투 대상 또는 자신/대상 없음 규칙을 사용한다. 캐릭터별 자동 발동 적용 목록은 아직 미지정이므로 기존 에셋을 임의 자동 전환하지 않았다.
- 5성의 개별 스킬만 짧은 Cinemachine 클로즈업. 클릭/ESC 건너뛰기 및 카메라/틱 상태 복원.

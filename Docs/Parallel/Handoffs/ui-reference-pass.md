# UI reference pass — 2026-09-28

## 적용
- 사용자 제공 7장 이미지는 시각 가이드로 해석했다. 이미지 속 게임 규칙/재화/대원/로고는 가져오지 않았다.
- OperatorHubUI: 4열 세로 카드 갤러리, 희귀도/레벨 정렬, 초상(실제 Icon)/기물 이니셜 대체 표시, 선택 강조, 별도 상세 정보판. 기존 레벨/스킬/기보/공명 서비스 유지.
- EdictSelectorModal: 비용/극성 헤더, 극성 표식과 얇은 프레임, 효과/장착 비용/수용량 비교. 카드 목록에 스크롤과 마스크를 적용하고 다시 열 때 이전 카드는 즉시 숨긴다.
- StageSelectUI: 실제 OP-01~05 데이터를 참조하는 정규 작전 선택도. 기존 브리핑 호출과 선택 강조 연결. 연결선은 시각적 목록이며 해금 규칙을 추가하지 않는다.
- 로비 부관 숨김과 배경 전용 표시 유지. 씬/전투 규칙/저장/밸런스 변경 없음.

## 검증
- 연결된 Unity 6000.3.10f1 프로젝트 경로 확인, Team.ps1 실행권 획득 후 검증.
- 컴파일 오류 없음. 기존 KiaraActive1/2/3 AbilityDefinition Missing types 3건은 잔존.
- EditMode 전체 144/144 통과 (job 19397670966b403dacad145d4698fd8f).
- 최종 정보 갱신/선택 강조 수정 후 아웃게임 테스트 17개 재통과. Play에서 카드 레벨 표시와 OP-03 선택 반전 재확인. Play 종료 및 실행권 반납 완료.
- OutgameScene Play: 대원 4개 표시, 두 번째 대원 엘레나 선택/레벨 탭/정렬, OP 지도 5노드 표시/OP-03 브리핑 열기 및 닫기, 일반 칙령 모달 열기/내용 확인/닫기 수행.
- 검증 중 실제 재화 사용/장착 변경은 수행하지 않음. 개별 소비 규칙은 기존 테스트에 의존.
- 새로운 게임 런타임 예외 없음. 검증용 임시 코드에서 빈 씬 및 비동기 화면 전환 완료 전 조회로 NullReference 2회 발생: 정식 씬에서 전환/조회를 분리해 재검증 완료, 제품 코드 문제가 아님.
- Captures/UIReference/operator-level-native.png, operations-native.png, mod-native.png는 실제 ScreenCapture 결과. manage_camera 도구의 캡처는 색공간 차이와 일시정지를 유발하여 최종 색상 판단에 사용하지 않음.
- 대원 원화가 없는 현재 데이터는 이니셜로 표시한다. 3D 도시 지도/전투 HUD 재구성은 이 패스에 포함하지 않았다.

## 변경 결과

두 재화 기획서에 정의된 계정 재화를 `SaveData`에 추가했다. 기존 JSON은 `economy-v0.bak`으로 보존하고, 기존 편성·대원·기보 진행은 유지한 채 기본 재화와 전력 회복 상태를 보충한다.

`EconomyService`가 UTC 기준 6분당 전력 1 회복, 최대 999 오버플로우, 슈트 레벨 기반 120~180 상한, 비상 전력 팩, 공명석 충전(40/40/60/60/80/100/120/150/180/200, 하루 10회), 코어 1:100 교환, 스테이지 출격 영수증을 담당한다. 결과 화면은 영수증 기준으로 크레딧·공명석·전술 기록 칩을 한 번만 지급하고, 기존 계정 TP/킹 TP 중복 지급과 슈트 레벨 자동 증가를 제거했다.

개인 TP는 계정 화폐에서 분리했다. 대원별 레벨·공명·숙련도 및 기존 대원별 기보 예산만 사용한다. 성급별 공명 레벨 캡(3★ 30/45/55, 4★ 40/60/70, 5★ 50/70/85), 돌파 레벨 조건과 증표·크레딧 비용을 적용하며 돌파 시 레벨을 초기화하지 않는다. 전술 작전기록 T1~T4(200/1,000/4,000/20,000 EXP)와 공식 필요 EXP 곡선, EXP의 20% 크레딧 주입 비용을 `OperatorHubUI`에 연결했다. 칙령 일반 슬롯 변경은 1,500 크레딧을 차감한다.

`RecruitmentService`는 설정된 배너를 우선 사용하고, 배너 에셋이 없어도 공식 40인(5★ 10명·4★ 14명·3★ 16명) 런타임 로스터와 Kiara 픽업을 제공한다. 1/10회 소집, 허가증 우선·부족분 공명석 150, 10연차 4성 이상 보장, 2% 5성·8% 4성·80회 천장, 픽업 마일리지 300 교환, 중복 증표 1/5/15를 구현했다.

공식 레벨 명세의 OP-01~OP-05와 크레딧/작전기록 자원 작전(CE-1~3, LS-1~3)을 StageData 에셋으로 연결했다. 첫 클리어·반복·확률 드랍은 T1~T4 계정 인벤토리로 분리되어 결과 화면에 등급별로 표시된다.

상단 헤더에 전력·크레딧·공명석을 표시하고 + 버튼으로 전력/코어 보급 모달을 연다. 전력·크레딧·공명석 부족과 작전 경제 설정 누락을 모달에서 설명한다.

## 남은 설정과 제한

부관 이미지는 명세대로 직접 설정하는 영역이므로 이번 범위에서 새 이미지를 생성하거나 교체하지 않았다. 40인 중 새 초상·전투 프리팹이 없는 대원은 ID·성급·기물·직군 메타데이터로 먼저 소집·저장되며, 콘텐츠 제작 시 같은 ID의 정식 UnitData/초상을 넣으면 자동으로 교체된다.

기존 AbilityDefinition의 `ApplyBuffAbilityEffect`/`DealAreaDamageAbilityEffect` 직렬화 타입 오류 3건은 경제 변경과 무관하다. 콘솔 기준 전체 오류 0건으로 보고하지 않는다.

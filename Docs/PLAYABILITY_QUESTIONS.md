# 완성도 개선 — 확인이 필요한 기획

2026-09-29. 답변 대기 때문에 구현을 멈추지 않으며, 아래 미정 규칙은 임의로 확정하지 않는다.

## 1. 정식 작전 구성 (우선)
- 조사 당시 OP-01~05, CE-1~3, LS-1~3은 적 배치가 비어 있고, 기존 STG/BOSS 네 작전에는 경제 설정이 빠져 정상 출격이 막혀 있었다.
- OP-01~04에 기존 STG 1-1~1-3, BOSS 1-4의 적 진형만 순서대로 재사용해 연결했다. 기존 OP 목표/보상과 적 능력치는 그대로다. 최종 난이도 확정이 아닌 플레이 흐름 복구용 구성이다. OP-05와 자원 작전은 아직 미완성이다.
- 질문: 기존 네 작전을 OP 캠페인에 통합할 것인가, OP 전용 적 구성으로 새로 설계할 것인가? 자원 작전의 적 구성과 승리 조건은 무엇인가?

## 2. 스킬 발동 규칙
- 정식 BattleManager 생성 유닛에는 SPComponent와 SubclassComponent가 연결되지 않는다. SP 자동 회복은 Update 기반이며, 충전 완료 즉시 초기화/OnSPFull을 보내는 기존 구현이다.
- 질문: 액티브 스킬은 SP 충전 후 수동 발동인가, 서브클래스별 자동 발동인가? 배치/일시정지 중 회복은 중단하는가?
- 단순히 컴포넌트만 붙이면 배치 중 회복과 자동 발동이 생길 수 있어 이번에는 연결하지 않았다. KiaraActive1/2/3의 누락 효과 타입도 복구가 필요하다.

## 3. 편성 코스트
- 현재 대원별/합계 코스트 표시만 있다. 배치 중 코스트 표시는 제거했다.
- 질문: 편성 최대 코스트는 고정인가, 지휘관 성장에 따라 증가하는가? 상한 값/성장식이 필요하다.

## 4. 배치 확정과 징집병
- 현 구현은 전투 시작 시 앞쪽 행의 빈 칸에 징집병을 자동 생성한다. 킹 배치 여부는 시작 전 검증하도록 보강했다.
- 질문: 나머지 편성 대원도 모두 배치해야 시작 가능한가? 자동 징집병 충원은 최종 규칙인가? 배치 철회/교체를 허용할 것인가?

## 5. 다음 완성도 작업
- 최우선: 정식 OP 전투 콘텐츠 연결 및 실제 한 판 승패·보상·복귀 검증.
- 스킬 데이터 복구와 SP/행동 연동, 전투 조작 안내 및 행동 실패 이유 세분화.
- 캐릭터 초상/기물 모델/공격·피격 연출/효과음. 현재 일부 데이터는 임시 기물·텍스트 표시를 사용한다.
- 기존 카메라 SendMessage, 물 셰이더 Enum drawer 오류 정리.

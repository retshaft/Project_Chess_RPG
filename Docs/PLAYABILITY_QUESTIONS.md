# 전투 완성도 — 확정 규칙과 남은 설계

2026-09-30 사용자 답변을 기준으로 갱신. 과거 질문 대신 확정 내용과 후속 작업을 구분한다.

## 확정 규칙

- **정식 작전:** OP 전용 적 구성으로 새로 설계한다. 캠페인 난이도는 높이되, 구체적인 레벨 디자인과 적 수치·진형은 추후 확정한다. 현재 연결된 임시 구성을 최종안으로 취급하지 않는다.
- **스킬:** SP 회복 규칙(자동/공격/피격)에 따라 충전한다. 완충된 스킬은 기본 수동 발동이며 자동 발동 계열도 지원한다. 충전 완료 자체가 SP를 소비하지 않는다. 배치·전투 연출 중에는 전투 틱이 멈춰 충전도 멈춘다.
- **편성:** 상한은 성장하지 않는 고정값이며 초기 20. 기준 편성은 킹(현재 3)+퀸 5+룩 4+비숍 3+나이트 3+선택 폰 2명(2)으로 합계 20이다. 폰 1, 나이트/비숍 3, 룩 4, 퀸 5. 킹은 슈트별 값. 특수 예외는 별도 비용 덮어쓰기 설정을 사용한다.
- **배치:** 킹은 e1(4,0)에 자동 배치한다. 다른 대원을 전부 배치할 의무는 없다. 전투 시작 시 앞줄 빈칸을 징집병으로 반드시 채운다. 수동 배치 대원은 배치 단계에서만 우클릭으로 철회하고 다시 배치할 수 있다.
- **카메라:** 보드와 조작 가독성을 우선한다. 수동 팬·줌·회전·복귀와 짧은 전투 시작 연출을 유지한다. 개별 스킬 클로즈업은 5성만 허용한다.

## 이번 구현

- 편성 합계/카드에 기물별 비용을 통일하고 20 초과 편성 및 출격을 차단했다. 기존 초과 저장 덱을 자동 삭제하지 않는다. 편성 해제로 조정할 수 있다.
- 킹 자동 배치, 킹 카드 제외, 배치 중 철회와 카드 복구, 미배치 대원을 남긴 전투 시작, 징집병 필수 데이터 검증.
- 정식 전투에 SP 표시 연결. 실제 전투의 SP 변경/소비를 기존 행동·변경 기록 경로에서 처리하며 표시 컴포넌트의 중복 충전을 제거했다.
- 스킬 데이터에 수동/자동 발동 구분 추가. 실제 장착 스킬을 발동하며, 효과 데이터가 없는 스킬은 소비 없이 거절한다. 자동 대상형 스킬은 기존 전투 대상, 자신 대상형은 자신을 사용한다.
- SP 회복 기본값은 기존 SPComponent의 기준(자동 초당 1, 공격/피격 1)을 사용한다. 선택된 스킬의 SP 상한·시작 SP·레벨을 따른다. 구형 무스킬 디버그 유닛의 기존 계산은 보존한다.
- 5성 스킬 발동 요청 성공 시 짧은 클로즈업. 클릭/ESC로 건너뛰며 원래 전투 카메라와 틱 상태로 복귀한다.

## 남은 콘텐츠와 확인 사항

1. OP별 적 종류·레벨·진형·단계별 난이도, 자원 작전의 전용 적 구성은 후속 기획 대상이다.
2. 일부 기존 스킬 에셋에는 누락된 효과 타입 또는 미완성 효과 데이터가 있다. 발동 기반 검증은 런타임 전용 검증 스킬로 수행했으며, 모든 대원의 스킬 효과 완성을 의미하지 않는다.
3. 자동 발동을 적용할 실제 캐릭터/스킬 목록과 대상 우선순위가 추가로 필요하다. 기존 에셋은 기본 수동 발동을 유지한다.
4. 예측은 기존 복제 상태 격리를 유지한다. 현재 예측 결과는 이동·피해 중심이며, 미래 SP 회복과 자동 스킬 연쇄 전체 예측은 이번 범위에 포함하지 않는다.
5. 킹의 슈트별 구체 비용은 기존 데이터 값을 사용했다. 새 슈트 비용을 임의로 정하지 않았다.
